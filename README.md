# RuN by Rj downloads

Official development downloads and signed Fedora Flatpak updates.

**[Install RuN by Rj](https://nrajesh0.github.io/run-by-rj-downloads/)**

The website becomes available after the first successful release and Pages
workflow. Read the [installation and update guide](docs/github-pages-installation.md).

This repository contains public distribution automation, documentation and
finished release files. Application source and private signing keys are held
separately. GitHub's automatically generated source archives contain this
small downloads repository, not the application source.

The app is a development build. Full installed security, recovery and update
acceptance remains pending. Back up your notes before updates.

Original app code and branding are proprietary; official unmodified releases
may be used free of charge under [LICENSE](LICENSE). Third-party licenses still
apply. AppStream listing text alone uses [CC0](METADATA-LICENSE).

For installation problems or security reporting, contact
[Nrajesh0](https://github.com/Nrajesh0). Do not publish notes, PINs, recovery words,
private keys or access tokens in issues.

Pages runs its signature verifier and public distribution configuration from a
fixed reviewed commit. The publishing token is scoped to this repository and has no Workflows permission. Changing files on main does
not change the verifier used by the pinned workflow. Signing keys and passphrase
remain private; the fingerprint in distribution.json is intentionally public.
